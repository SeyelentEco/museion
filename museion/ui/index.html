            Your notes

            Write down what you learn, what you have and what worked: a repair, a remedy, which seeds grew. Records such as stores, medicines and maintenance are tables that agents keep up to date for you, after you press Allow.

            They are plain files in the library's notes folder, so any text editor opens them too. Every change keeps the version before in the folder's .history.

                    Radio optional

                    A Meshtastic radio passes short text messages to other radios nearby, a few kilometres a hop, with no phone network or internet. If you have one, plug it in by USB (or put it on the same network) and connect it here: a Radio tab then shows the messages, and the Radio operator agent can read them and send replies you allow. Without one, nothing changes.

                    Its port: COM5 on Windows, /dev/ttyUSB0 or /dev/ttyACM0 on Linux, /dev/cu.usbserial… on a Mac. For a radio on the network, tcp: and its address, like tcp:192.168.1.40.

                    This drive

                    The drive's manifest lists every archive and model on it with its checksum. Checking reads each one through, so a damaged file is found before it is needed.

                    Prepare a drive

                    Everything Museion needs on one removable drive: the archives, the models, the helper programs for any graphics card, and Museion itself with the Python that runs it. It runs from the drive on any computer, whatever letter the drive comes up under, with nothing installed and no internet there. Downloads resume, so a drive can be prepared over several sittings.

                    The drive's root, or any empty folder that will be copied to one. Use exFAT for a drive that must work on a Mac too.
                    Each computer picks the one that fits it. The small one runs anywhere, slowly; the large ones want a graphics card with 8 GB or more.
                    One per kind of graphics card the drive may meet. All three is 700 MB.

                    Advanced

                    The assistant's instructions and limits — the system prompt, how many passages it reads, how long an answer may run — are plain text. Museion reads the file below before every question, so an edit shows in the very next answer with no restart. Fields you leave out keep their defaults; a file that won't parse is ignored.
